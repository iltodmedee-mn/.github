### Бид юу хийдэг вэ

Монгол Улсын 140 төрийн байгууллагын сайтаас мэдээг 30 минут тутам цуглуулж, **баримтыг пи-араас ялгаж**, эх сурвалжийн холбоостой нь хүргэдэг нээлттэй эхийн мэдээллийн сайт.

| | |
|---|---|
| 📰 **Мэдээ** | Мэдээ бүр эх .gov.mn холбоостой, баримт ба пи-ар тусдаа |
| 💰 **Төсөв, тендер** | Шилэн данс, ҮСХ-ны албан ёсны тоо |
| 🧾 **Татвар** | Цалингийн татварын тооцоолуур (2027, 2028 оны өөрчлөлттэй) |
| 🏛️ **Улстөрчид** | УИХ-ын гишүүдийн хөрөнгө, орлогын мэдүүлэг, ирц |
| 🔍 **Ил тод** | AI-д зарцуулсан цент бүр [нийтэд ил](https://iltodmedee.mn/transparency) |
